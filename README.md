# EBAC registry exercise

[Leia em português](README.pt-BR.md)

A C console exercise from an EBAC IT course. The source implements a Portuguese-language menu for creating, finding and deleting registry entries using local text files.

## Explore the source

[`Cartorio.c`](Cartorio.c) contains the menu and file operations. The original exercise assumes a Windows console.

**Use synthetic data only.** The exercise stores entries in plain text and has limitations in credential handling, input validation and file handling. Keep any experimentation in a disposable directory.

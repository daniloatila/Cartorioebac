# Exercício de cadastro da EBAC

[Read in English](README.md)

Exercício de programação em C para terminal, desenvolvido em um curso de TI da EBAC. O código implementa um menu em português para cadastrar, consultar e excluir registros armazenados em arquivos de texto locais.

## Explorar o código

[`Cartorio.c`](Cartorio.c) contém o menu e as operações com arquivos. O exercício original foi escrito para o terminal do Windows.

**Use somente dados fictícios.** O exercício guarda os registros em texto aberto e tem limitações no tratamento de senhas, entradas e arquivos. Para experimentar, use uma pasta descartável.
